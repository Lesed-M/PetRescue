# PetRescue

A web application for pet adoption and donations. Users can list pets for adoption, adopt available pets and donate to support the cause. Available pets and adopted pets are displayed separately.

## Tech stack
- ASP.NET MVC and C#
- SQL Server
- LINQ / Lambda queries
- Bootstrap [and a donation progress bar, if you built one]
- jQuery for DOM manipulation
- [Pet images stored as Base64 strings / file paths]

## Features
- List a pet for adoption
- Browse available pets
- Adopt a pet
- Make a donation
- Showcase of adopted pets

## How to run
1. Open the `.sln` file in Visual Studio.
2. Update the connection string in `Web.config` to point to your SQL Server instance.
3. [Run the database script or migration.]
4. Press F5 to start the project.
